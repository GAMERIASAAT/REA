# REA — Reverse Engineering Anything

Opencode-powered skills and commands for reverse engineering, binary analysis, deobfuscation, and vulnerability research.

## Structure

```
REA/
├── skills/             # Opencode skills for RE tasks
│   └── example-skill/
│       ├── skill.md    # Skill definition
│       └── README.md   # Skill documentation
├── commands/           # Opencode slash commands
│   └── re.md           # Example RE command
└── README.md
```

## Getting Started

1. Clone this repo into your Opencode skills/commands directory:
   ```bash
   # Skills
   git clone https://github.com/GAMERIASAAT/REA.git ~/.opencode/skills/REA

   # Commands
   git clone https://github.com/GAMERIASAAT/REA.git ~/.opencode/commands/REA
   ```

2. Reload Opencode or restart your session.

## Included

- `skills/example-skill/` — Template skill for building RE-focused assistant skills
- `commands/re.md` — Example slash command for reverse engineering workflows
